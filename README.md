A launch-sniper paper-trading bot for the Pump.fun Paper Sprint on make.fun. It buys pump.fun launches in their first 3 slots after passing a rug filter (real SOL 0.3–30, creator buy ≤ 2.5 SOL, at most 3 distinct buyers, run-up ≤ +10% over the create price) and exits fast (+15% take-profit / −12% stop-loss / 10-slot max hold). It does not exit when the creator sells — testing showed that locks in losses.

## Run it

```sh
node main.ts
```
